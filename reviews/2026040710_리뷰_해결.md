## 3-1. innerHTML XSS 방어 (중요도: 높음)

### 문제

`src/user_js/user_request.js`의 `renderList()` 함수(약 45번째 줄)와 `src/user_js/user_song.js`의 `renderChart()` 함수(약 45번째 줄)에서 서버 데이터를 `innerHTML`에 직접 넣고 있어요.

누군가 제목에 `<img src=x onerror="alert('해킹')">` 같은 걸 넣으면 방문자 브라우저에서 실행돼요.

### 해결 방법

**Step 1.** `src/user_js/user_request.js` 파일 맨 위에 이스케이프 함수를 추가하세요.

```js
// 수정 전 (user_request.js 1번째 줄)
const API_BASE = 'https://api.fullstackfamily.com/api/rawbeef/v1/requests';

// 수정 후
function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

const API_BASE = 'https://api.fullstackfamily.com/api/rawbeef/v1/requests';
```

**Step 2.** `renderList()` 함수 안에서 사용자 입력 데이터가 들어가는 부분을 `escapeHtml()`로 감싸세요.

```js
// 수정 전
el.innerHTML = `
  ...
  <span class="text-sm font-medium text-gray-900 dark:text-gray-100 self-center flex items-center gap-2">
    ${item.title}
    ...
  </span>
  ...
  <p class="text-sm text-gray-700 dark:text-gray-300 leading-relaxed whitespace-pre-wrap mb-5">${item.content}</p>
  ...
  <p class="text-sm text-gray-700 dark:text-gray-300 m-0 whitespace-pre-wrap">${item.comment.content}</p>
  ...
`;

// 수정 후 — ${item.title}, ${item.content}, ${item.comment.content}를 escapeHtml()로 감싸기
el.innerHTML = `
  ...
  <span class="text-sm font-medium text-gray-900 dark:text-gray-100 self-center flex items-center gap-2">
    ${escapeHtml(item.title)}
    ...
  </span>
  ...
  <p class="text-sm text-gray-700 dark:text-gray-300 leading-relaxed whitespace-pre-wrap mb-5">${escapeHtml(item.content)}</p>
  ...
  <p class="text-sm text-gray-700 dark:text-gray-300 m-0 whitespace-pre-wrap">${escapeHtml(item.comment.content)}</p>
  ...
`;
```

**Step 3.** `src/user_js/user_song.js`에도 동일하게 적용하세요.


`renderChart()` 함수 안에서:

```js

<div class="px-2 py-3 text-left text-sm font-semibold text-gray-900 dark:text-gray-100">${s.title}</div>
<div class="px-2 py-3 text-left text-xs text-gray-500 dark:text-gray-400">${s.artist}</div>
```

```html
  </button>
</a>

<!-- 수정 후 — <button>을 삭제하고 <a>에 스타일을 적용 -->
<a href="./user_request.html" target="_blank"
   class="inline-flex items-center gap-2 mt-6 px-7 py-3 bg-red-600 hover:bg-red-700 text-white text-sm font-semibold rounded cursor-pointer transition-colors duration-150 no-underline">
  <svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24" stroke="currentColor" class="w-4 h-4">
```

## 3-10. 테마 저장 방식 통일 (중요도: 중간)

### 문제

`soyu/header.js`는 `sessionStorage`를, `src/user_js/theme.js`는 `localStorage`를 사용해요.

### 해결 방법

**Step 1.** `soyu/header.js`에서 `sessionStorage`를 `localStorage`로 변경하세요.

```js
// 수정 전 (soyu/header.js — initTheme 함수 안)
function applyTheme(dark) {
  if (dark) {
    html.classList.add('dark');
    themeIcon.textContent = '☀️';
    themeLabel.textContent = '라이트모드';
    sessionStorage.setItem('theme', 'dark');       // ← sessionStorage
  } else {
    html.classList.remove('dark');
    themeIcon.textContent = '🌙';
    themeLabel.textContent = '다크모드';
    sessionStorage.setItem('theme', 'light');      // ← sessionStorage
  }
}

applyTheme(sessionStorage.getItem('theme') !== 'light');  // ← sessionStorage

// 수정 후
function applyTheme(dark) {
  if (dark) {
    html.classList.add('dark');
    themeIcon.textContent = '☀️';
    themeLabel.textContent = '라이트모드';
    localStorage.setItem('theme', 'dark');          // ← localStorage로 변경
  } else {
    html.classList.remove('dark');
    themeIcon.textContent = '🌙';
    themeLabel.textContent = '다크모드';
    localStorage.setItem('theme', 'light');         // ← localStorage로 변경
  }
}

applyTheme(localStorage.getItem('theme') === 'dark');     // ← localStorage로 변경
```

주의: 초기값 비교 로직도 살짝 바뀌었어요.
- **수정 전**: `sessionStorage.getItem('theme') !== 'light'` → 값이 없으면(null) dark
- **수정 후**: `localStorage.getItem('theme') === 'dark'` → 값이 없으면(null) light

이렇게 하면 `src/user_js/theme.js`와 동일한 동작이 돼요.

> **쉽게 말하면:** `sessionStorage`는 "메모지" (탭 닫으면 사라짐), `localStorage`는 "수첩" (계속 남아있음)이에요. 테마 설정은 수첩에 적어두는 게 자연스러워요.

## 3-14. 댓글 삭제 버튼 조건 추가 (중요도: 중간)

### 문제

`soyu/admin_request.html`의 `renderRequests()` 함수에서, 댓글이 없는 신청에도 "삭제" 버튼이 표시되고 클릭하면 `req.comment.id`에서 에러가 발생해요.

### 해결 방법

```js
// 수정 전 (admin_request.html — renderRequests() 안)
const deleteBtn = document.createElement('button');
deleteBtn.className = 'hover:text-red-600 font-black text-lg';
deleteBtn.textContent = '삭제';
deleteBtn.addEventListener('click', async () => {
  if (confirm('이 댓글을 정말 삭제할까요?')) {
    await deleteComment(req.comment.id);
    await loadRequests();
  }
});
btnGroup.append(registerBtn, deleteBtn);

// 수정 후 — 댓글이 있을 때만 삭제 버튼 추가
btnGroup.appendChild(registerBtn);

if (req.comment) {
  const deleteBtn = document.createElement('button');
  deleteBtn.className = 'hover:text-red-600 font-black text-lg';
  deleteBtn.textContent = '삭제';
  deleteBtn.addEventListener('click', async () => {
    if (confirm('이 댓글을 정말 삭제할까요?')) {
      await deleteComment(req.comment.id);
      await loadRequests();
    }
  });
  btnGroup.appendChild(deleteBtn);
}
```

> **쉽게 말하면:** 아직 쓴 적 없는 일기를 지우려고 하면 "일기가 없어!" 에러가 나겠죠. 일기가 있을 때만 "삭제" 버튼을 보여주면 돼요.
