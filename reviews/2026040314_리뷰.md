- 이전 리뷰에서 지적한 11개 항목 중 **7개를 수정**했어요! 정말 대단해요!

```js
// user_request2.html 166~168번째 줄 — 좋은 습관이에요!
```

### 3-1. `pages/` 폴더의 sidebar.js import 에러 (중요도: 높음)

**현재 상태:**
```js
// pages/dashboard.js (2번째 줄)

// pages/category.js (2번째 줄)
import { createSidebar } from '../components/sidebar.js';
```

**왜 개선하면 좋을까?**
`components/sidebar.js` 파일은 PR #15에서 삭제되었어요. 그래서 `pages/` 폴더의 3개 JS 파일이 **존재하지 않는 파일을 import**하고 있어요. 이 페이지들을 열면 콘솔에 에러가 발생해요.

**추천:** `components/sidebar.js`를 다시 만들거나, `soyu/sidebar.js`의 방식처럼 각 HTML에서 직접 불러오는 방식으로 변경하세요.

### 3-3. `innerHTML`로 사용자 입력을 넣으면 위험해요 — XSS (중요도: 높음)

**현재 상태:**
```js
// soyu/admin_category.html — spanTitle에 textContent 사용 (안전!)
spanTitle.textContent = item.title;

// woohyun/user_request.html 333번째 줄 근처 — innerHTML 사용 (위험!)
row.innerHTML = `
  <div class="cell title">${s.title}</div>
  <div class="cell singer">${s.artist}</div>
`;
```

**왜 개선하면 좋을까?**
`innerHTML`에 사용자가 입력한 값을 직접 넣으면, 악의적인 사용자가 `<script>` 태그를 넣어 다른 사용자의 정보를 빼갈 수 있어요 (이것을 XSS 공격이라고 해요). `user_request2.html`에서는 `escHtml()` 함수로 방어하고 있는데, 다른 파일에서는 이 방어가 빠져 있어요.

**추천:** `innerHTML`에 사용자 입력값을 넣을 때는 반드시 특수문자를 치환하세요.
```js
// 이 함수를 공통으로 사용하면 좋아요
function escHtml(s) {
  return s.replace(/[&<>"']/g, c =>
    ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'})[c]
  );
}

// 사용할 때
row.innerHTML = `<div class="cell title">${escHtml(s.title)}</div>`;
```

**현재 상태:**

**추천:** `vite.config.js`의 `input`에 추가하세요.
```js
user_request2: resolve(__dirname, 'woohyun/user_request2.html'),
```

### 3-5. `user_song.html` — LocalStorage 파싱 에러 처리 없음 (중요도: 중간)

**현재 상태:**
```js
// woohyun/user_song.html
const categories = JSON.parse(localStorage.getItem('myCategory'));
```

**왜 개선하면 좋을까?**
`localStorage`에 저장된 값이 올바른 JSON이 아닐 수도 있어요 (예: 직접 개발자 도구에서 값을 수정했거나, 다른 코드에서 잘못 저장한 경우). 이때 `JSON.parse()`가 에러를 발생시켜서 페이지 전체가 멈출 수 있어요.

**추천:**
```js
let categories = [];
try {
  categories = JSON.parse(localStorage.getItem('myCategory')) || [];
} catch (e) {
  categories = [];
}
```

### 3-6. `admin_song.html` — 미사용 변수와 이벤트 파라미터 (중요도: 낮음)

**현재 상태:**
```js
// soyu/admin_song.html
// 1. 미사용 querySelectorAll (생성 후 아무것도 안 함)
const categoryDeleteBtn = document.querySelectorAll('.categoryDeleteBtn');

deleteBtn.addEventListener('click', function (click) {
  deleteSong(index);
});
```

**왜 개선하면 좋을까?**
사용하지 않는 코드가 있으면 나중에 "이게 뭐하는 코드지?" 하고 혼란스러울 수 있어요. 이벤트 파라미터 이름도 보통 `e` 또는 `event`로 쓰는 것이 관례예요.

**추천:**
```js
// 미사용 줄 삭제
// const categoryDeleteBtn = document.querySelectorAll('.categoryDeleteBtn');

// 파라미터 수정 (사용하지 않으면 생략해도 됨)
deleteBtn.addEventListener('click', function () {
  deleteSong(index);
});
```

**추천:**
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOi...",
    "user": { "id": 1, "name": "관리자" }
  }
```
