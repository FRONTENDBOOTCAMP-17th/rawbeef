## 3-1. `pages/` 폴더의 sidebar.js import 에러 (중요도: 높음)

### 문제

`pages/dashboard.js`, `pages/category.js`, `pages/song.js` 3개 파일이 삭제된 `components/sidebar.js`를 import하고 있어서 페이지 로드 시 에러가 발생해요.

### 해결 방법

두 가지 방법 중 선택하세요.

**방법 A: soyu/ 방식처럼 HTML에서 직접 로드하기 (간단)**

`pages/` 폴더에 sidebar.js를 새로 만들고, HTML에서 로드합니다.

**Step 1.** `pages/sidebar.js` 파일을 만듭니다:

```js
// pages/sidebar.js
const menuItems = [
  { href: './dashboard.html', label: '대시보드' },
  { href: './category.html', label: '카테고리 관리' },
  { href: './song.html', label: '노래 관리' },
];

function createSidebar() {
  const currentPage = './' + location.pathname.split('/').pop();

  const aside = document.createElement('aside');
  aside.className = 'w-64 bg-white border-r p-6 flex-shrink-0';

  const title = document.createElement('h2');
  title.className = 'text-xl font-bold mb-6';
  title.textContent = '관리자';
  aside.appendChild(title);

  const nav = document.createElement('nav');
  nav.className = 'flex flex-col gap-2';

  menuItems.forEach((item) => {
    const a = document.createElement('a');
    a.href = item.href;
    a.textContent = item.label;
    const isActive = currentPage === item.href;
    a.className = isActive
      ? 'block py-2 px-4 bg-blue-100 text-blue-700 rounded font-medium'
      : 'block py-2 px-4 hover:bg-gray-100 rounded';
    nav.appendChild(a);
  });

  aside.appendChild(nav);
  return aside;
}

document.addEventListener('DOMContentLoaded', () => {
  const container = document.getElementById('sidebar-container');
  if (container) {
    container.replaceWith(createSidebar());
  }
});
```

**Step 2.** 각 HTML 파일에 `<div id="sidebar-container"></div>`과 `<script src="./sidebar.js"></script>`를 추가합니다.

**Step 3.** 각 JS 파일에서 import 줄을 삭제합니다:

```js
// 수정 전 (pages/dashboard.js 2번째 줄)
import { createSidebar } from '../components/sidebar.js';

// 수정 후 — 이 줄을 삭제하세요
```

**방법 B: components/sidebar.js를 다시 만들기**

`components/sidebar.js`를 새로 만들어 원래 import가 동작하도록 합니다. 내용은 위의 `pages/sidebar.js`와 동일하되, `export` 키워드를 추가합니다.

> **쉽게 말하면:** 가게에서 "사이드바"라는 부품을 주문했는데, 창고(components/)에서 물건을 치워버려서 배송이 안 되는 상황이에요. 창고에 다시 물건을 넣거나(방법 B), 직접 가져다 쓰는 방식(방법 A)으로 해결하면 돼요.

## 3-2. `user_request.html`과 `user_request2.html` 역할 중복 (중요도: 중간)

### 해결 방법

**Step 1.** `user_request.html`을 기본 파일로 정하고, API가 준비될 때까지 목업 데이터를 사용합니다.

```js
// woohyun/user_request.html의 fetch 부분을 이렇게 수정

// API 사용 가능 여부 (API 준비되면 true로 변경)
const USE_API = false;

async function loadRequests(page = 1) {
  if (USE_API) {
    // 실제 API 호출
    const res = await fetch(`${API_BASE}?page=${page}`);
    return await res.json();
  } else {
    // 목업 데이터 (user_request2.html에서 가져옴)
    return generateMockData(page);
  }
}
```

**Step 2.** `user_request2.html`에서 목업 데이터 생성 함수와 `escHtml()` 함수를 `user_request.html`로 옮깁니다.

**Step 3.** 통합이 완료되면 `user_request2.html`을 삭제하고 `vite.config.js`에서도 제거합니다.

> **쉽게 말하면:** 같은 메뉴의 레시피 노트가 2장 있으면 어느 걸 따라해야 할지 헷갈리잖아요. 하나로 합쳐서 "재료가 없으면 대체재 사용"이라고 적어두는 게 깔끔해요.

## 3-3. XSS 방어 — `escHtml()` 공통화 (중요도: 높음)

### 문제

`innerHTML`에 사용자 입력을 직접 넣으면 악성 스크립트가 실행될 수 있어요. `user_request2.html`에만 방어 코드가 있고, 다른 파일에는 없어요.

### 해결 방법

**Step 1.** `src/utils.js` 파일을 만들어 공통 함수를 정의합니다:

```js
// src/utils.js
export function escHtml(s) {
  return s.replace(/[&<>"']/g, c =>
    ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' })[c]
  );
}
```

**Step 2.** `innerHTML`을 사용하는 모든 곳에서 이 함수를 적용합니다:

```js
// 수정 전 (woohyun/user_song.html의 차트 렌더링)
row.innerHTML = `<div class="cell title">${s.title}</div>`;

// 수정 후
row.innerHTML = `<div class="cell title">${escHtml(s.title)}</div>`;
```

또는 `innerHTML` 대신 `textContent`를 사용하면 자동으로 안전해요:

```js
// innerHTML 대신 textContent 사용 (더 안전한 방법)
const titleDiv = document.createElement('div');
titleDiv.className = 'cell title';
titleDiv.textContent = s.title;  // HTML 태그가 자동으로 무력화됨
row.appendChild(titleDiv);
```

> **쉽게 말하면:** 손님이 주문서에 "서버를 해킹하라"라고 쓸 수도 있잖아요. `escHtml()`은 그런 위험한 글자를 무력화하는 소독약이에요. 모든 손님 입력에 뿌려야 해요.

## 3-5. LocalStorage 파싱 에러 처리 (중요도: 중간)

### 문제

`JSON.parse(localStorage.getItem(...))`이 잘못된 데이터에서 에러를 발생시킬 수 있어요.

### 해결 방법

LocalStorage에서 데이터를 읽는 모든 곳에 `try-catch`를 추가합니다:

```js
// 수정 전 (woohyun/user_song.html)
const categories = JSON.parse(localStorage.getItem('myCategory'));

// 수정 후
let categories = [];
try {
  categories = JSON.parse(localStorage.getItem('myCategory')) || [];
} catch (e) {
  console.warn('카테고리 데이터를 불러올 수 없습니다:', e);
  categories = [];
}
```

같은 패턴을 사용하는 곳:
- `woohyun/user_song.html` — `myCategory`, `mySongs`
- `soyu/admin_category.html` — `myCategory`
- `soyu/admin_song.html` — `mySongs`
- `soyu/admin_request.html` — `requests`

> **쉽게 말하면:** 서랍(localStorage)에서 물건을 꺼낼 때, 서랍이 잠겨있거나 물건이 깨져 있을 수도 있잖아요. "꺼내다가 문제가 생기면 빈 상자를 쓰자"라고 미리 정해두는 거예요.

## 3-9. `api.md` JSON 예시 수정 (중요도: 중간)

### 문제

API 문서의 응답 예시가 정확한 JSON 형식이 아니에요.

### 해결 방법

API 문서에서 응답 예시를 수정합니다:

```markdown
<!-- 수정 전 -->
응답: {success, data: {token, user}}

<!-- 수정 후 -->
응답:
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOi...",

      "id": 1,
      "name": "관리자"
    }
  }

```

> **쉽게 말하면:** API 문서는 다른 팀원이 보고 코드를 작성하는 설명서예요. 설명서가 정확해야 제품(코드)도 제대로 만들 수 있어요.

## 3-10. 다크모드 토글 코드 분리 (중요도: 낮음)

### 문제

3개 파일에 같은 다크모드 토글 코드가 반복돼요.

### 해결 방법

**Step 1.** `woohyun/dark-toggle.js` 파일을 만듭니다:

```js
// woohyun/dark-toggle.js
function initDarkToggle(buttonId = 'themeToggle', iconId = 'themeIcon', labelId = 'themeLabel') {
  const html = document.documentElement;
  const btn = document.getElementById(buttonId);
  const icon = document.getElementById(iconId);
  const label = document.getElementById(labelId);

  if (!btn) return;

  function applyTheme(dark) {
    if (dark) {
      html.classList.add('dark');
      if (icon) icon.textContent = '☀️';
      if (label) label.textContent = '라이트 모드';
      localStorage.setItem('theme', 'dark');
    } else {
      html.classList.remove('dark');
      if (icon) icon.textContent = '🌙';
      if (label) label.textContent = '다크 모드';
      localStorage.setItem('theme', 'light');
    }
  }

  applyTheme(localStorage.getItem('theme') !== 'light');

  btn.addEventListener('click', () => {
    applyTheme(!html.classList.contains('dark'));
  });
}

document.addEventListener('DOMContentLoaded', () => {
  initDarkToggle();
});
```

**Step 2.** 각 HTML에서 기존 다크모드 JS 코드를 삭제하고 스크립트를 로드합니다:

```html
<script src="./dark-toggle.js"></script>
```

> **쉽게 말하면:** 소유 님이 사이드바를 `sidebar.js`로 분리한 것과 같은 방법이에요. 똑같은 코드가 여러 곳에 있으면 한 곳으로 모아두는 거예요.
